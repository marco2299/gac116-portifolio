# Página Pessoal — Marco Antonio Maia

Portfólio web desenvolvido para a disciplina **GAC116 – Programação Web** (Atividade Prática 2).

O projeto possui **duas versões equivalentes** do conteúdo, cada uma usando um framework CSS diferente:

| Versão | Framework | Caminho |
|--------|-----------|---------|
| 1 | Bootstrap 5 | [`bootstrap/`](bootstrap/) |
| 2 | Tailwind CSS | [`tailwind/`](tailwind/) |

A página inicial ([`index.html`](index.html)) permite escolher qual versão visualizar.

## Requisitos

- HTML, CSS e JavaScript
- Layout responsivo
- Tema claro e tema escuro
- Informações reais do estudante
- Organização visual consistente e boa navegação

## Como visualizar localmente

Abra o arquivo `index.html` no navegador ou sirva a pasta com um servidor estático, por exemplo:

```bash
npx serve .
```
